### 1.3 数据契约
- **close**：DatetimeIndex，唯一、递增、无时区的日线日期；列为唯一证券代码；非空；正且有限为有效价格；NaN/inf/非正值视为无有效报价并走缺价逻辑。重复日期/证券必须报错，不能groupby取平均掩盖。
- **target_weights**：索引是实际产生目标的决策日子集，不ffill；列与close一致；行完整有限非负，`sum<=1+1e-12`。缺行=没有新订单；全零行=明确清仓，不能与缺行混淆。某行部分NaN非法。单次权重和仅有`<=1e-12`浮点超额时按原比例归一到1，不能把真实超配悄悄归一。
- **trading_dates**取回测范围内price_data所有证券日期的并集，不能与有效因子日期做intersection后删除缺信号日期；因子预热数据不能移动5d分块起点。全市场某交易日完全缺失无法从该输入证明日历完整，在框架文档说明输入日历责任，不能造一个成交日。

BacktestResult保留旧字段以减少入口变动，并新增：
- equity_curve：归一化净值（资产金额/initial_cash）。
- daily_returns：首行0，后续当前净值/前日净值-1，费用已包含；首行是决策基准，不算一个收益期间。
- weights：每日收盘后的实际持仓金额/当日总净值，不再代表目标；迁移所有消费者和CSV说明。
- target_weights：稀疏目标矩阵；cash、holdings（份额）、fees（绝对金额）每日序列/矩阵。
- costs：费用/当日成交前净值，兼容旧字段但明确单位；不能直接把sum(costs)称为现金金额。
- turnover：实际成交总金额/当日成交前净值。
- trades：decision_date、execution_date、sec、side、price、quantity（绝对值）、notional、fee。
- execution_log：decision_date、execution_date（末日为None）、status（executed/no_trade/cancelled_missing_price/unexecuted_end）、reason、missing_codes。
- decision_log：由TargetPlan附加，含decision_date、eligible_count、top_n、status（target_created/skipped_insufficient）、exclusions。
- rebalance_dates：计划决策日期，保持旧含义；实际成交次数另从execution_log计算。
- initial_cash、config_snapshot：支撑指标单位和历史复现。

TargetPlan为定义在models.py的frozen dataclass，字段为`target_weights: pd.DataFrame`、`rebalance_dates: pd.DatetimeIndex`、`decision_log: list[dict]`。BacktestResult的trades为pd.DataFrame（空表也保留规定列），execution_log和decision_log为`list[dict]`；cash、fees为pd.Series，holdings为pd.DataFrame。MetricsConfig也定义在models.py，避免metrics与engine相互导入。

execute_backtest只负责账本，初始decision_log为空，rebalance_dates为输入目标行的日期；run_backtest通过`dataclasses.replace(result, decision_log=plan.decision_log, rebalance_dates=plan.rebalance_dates)`附加全部计划日期及资格记录。
研究直接调用execute_backtest时也必须附加同一TargetPlan，不重新计算资格，不遗漏未生成目标的计划日。配置快照分开记录实际生效的执行配置、选股配置与指标配置；不把MetricsConfig隐式塞进ExecutionConfig。

## 2. B1：实现自融资费用求解
覆盖BUG-07/08的金额守恒核心。修改/新增models.py、execution.py、tests/test_execution.py。

- [ ] 实现 `solve_target_amounts(before: float, old: np.ndarray, weights: np.ndarray, rate: float) -> tuple[float, np.ndarray, np.ndarray, float]`，返回after、target、delta、fee。

### 核心方程与算法
核心方程和算法必须采用：
```python
# 先验证before>0、0<=rate<1、数组同形且有限、old/weights非负、sum(old)<=before容差。
def residual(x):
    return x + rate * np.abs(weights * x - old).sum() - before
lo, hi = 0.0, before
for _ in range(100):
    mid = (lo + hi) / 2.0
    if residual(mid) > 0.0:
        hi = mid
    else:
        lo = mid
after = (lo + hi) / 2.0
target = weights * after
delta = target - old
fee = rate * np.abs(delta).sum()
```

定义金额容差 `1e-10 * max(1.0,before)`；求解后验证 `abs(after+fee-before)<=tol` 及 `after-target.sum()>=-tol`；不满足抛 ValueError，不能剪裁负现金掩盖错误。只对容差以内的结算残差置零。不使用固定金额阈值吞掉真实的小额交易；只有所有目标差均为数值容差内时允许 `no_trade` 且不改变原仓。
数学依据：`sum(weights)<=1` 且 `rate<1` 时残差函数严格递增，区间 `[0,before]` 包根，无需 scipy 求根依赖。

#### 精确测试：
```python
rate = 0.00005
V = 100000.0
# 首次建仓 old=[0], w=[1]
assert after == pytest.approx(V/(1+rate), rel=1e-10)
assert fee == pytest.approx(V*rate/(1+rate), rel=1e-10)
# 全仓A换B old=[V,0], w=[0,1]
assert after == pytest.approx(V*(1-rate)/(1+rate), rel=1e-10)
assert fee == pytest.approx(rate*(V+after), rel=1e-10)
```

## B4：唯一指标函数
**文件**：metrics.py、models.py、tests/test_backtest_metrics.py。

指标不四舍五入；展示层才舍入。结果首行基准 0 收益不计收益期间；后续持现金的零收益日仍是有效期间，不能 drop 所有 0。

### 定义：
- `total_return` = 最后归一化净值 - 1（含全部费用）。
- `annual_return` = (1+total)^(252/n) - 1，n 为有效收益期间数；n=0 返回 0。
- `annual_volatility` = std(r,ddof=1)*sqrt(252)，n<2 为 0。
- `sharpe` = mean(r-rf_daily)/std(r-rf_daily,ddof=1)*sqrt(252)，`rf_daily=(1.01)^(1/252)-1`；n<2 或分母 0 为 0。
- `max_drawdown` = min(equity/cummax(equity)-1)。equity_curve 首行是装饰性初始净值 1.0（资产/initial_cash），因此峰值序列自动包含初始本金 1；若实现传入的净值序列不含初始行，必须先在头部拼接初始值 1 再取 cummax，不得从首个实际净值起算峰值（[0.999,0.999,0.999] 须报 -0.001 而非 0）。
- `sortino` = mean(excess)*sqrt(252)/sqrt(mean(min(excess,0)^2))，使用全部收益期间作下行平方均值分母；无下行或无期间返回 0，并在文档说明此有限值约定。该结构与 quantstats 现实现一致（全样本分母、不中心化），差异仅在统一框架对 excess 扣减 rf（现有调用 rf=0），迁移后 sortino 数值可能微变，属预期统一。
- `calmar` = annual_return / abs(max_drawdown)，回撤为 0 返回 0。
- `win_rate` = 正收益期间数 / 非零收益期间数，无非零期返回 0，保留 quantstats 常用的排除零收益口径。
- `turnover_sum` = sum(turnover)，不从 weights.diff 重算。
- `cost_sum` = sum(fees)/initial_cash，定义为相对初始本金累计费用，另提供 `fee_amount_sum=sum(fees)`。
- `rebalance_count` = execution_log 中 status=executed 的次数，不是计划日期数；no_trade 不计成交次数。
- `calculate_yearly_returns` 按日收益年份分组乘积，首行 0 不改变年度值。

输入非法 NaN 收益、非正净值、配置年化<=0 或 rf<=-1 报 ValueError；合法空/无期间返回全 0 指标。内部构造结果必须保证净值和日收益一致，不修剪非法收益。

- [ ] 精确测试独立构造首行基准收益 0、随后收益 [-0.001, 0, 0] 与净值 [1.0, 0.999, 0.999, 0.999]，预期有效收益期间数为 3、`total_return=-0.001`、`max_drawdown=-0.001`；不能用测试函数自身产生预期。
- [ ] 测试有盈亏、全零、单期间、无下行、不同 rf、年界、initial_cash 不为 1 时 cost_sum。
- [ ] 默认 rf=.01、交易费率=.5bps 分开测试，不把无风险收益加到现金净值。
- [ ] `$PY -m pytest tests/test_backtest_metrics.py -q` 通过。
