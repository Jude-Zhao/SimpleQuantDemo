## 本次发现并修复的问题

### 回测持仓清零问题

原逻辑用 `0 -> NA -> ffill` 构造持仓矩阵，会导致调仓日被卖出的标的继续继承旧权重。修复后：

1. 非调仓日权重保持缺失。
2. 调仓日写入完整目标权重，包括未入选标的的 0。
3. 再整体前向填充。

补充测试：`test_run_backtest_clears_sold_positions_on_rebalance`。

### IC统计频率与文档口径差异

原研究/实盘入口使用全部交易日 IC。已修正为：核心 IC 函数仍支持全日期计算，但研究/实盘入口默认按调仓日样本筛选 IC，再计算 ICIR。
