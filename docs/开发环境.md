# 开发环境约定

## Conda环境

后续项目运行、调试、依赖安装默认使用以下Conda虚拟环境：

| 项目 | 约定 |
|------|------|
| 虚拟环境名称 | `QuantitativeTrading` |
| Python路径 | `D:\Coding\APPS\Miniconda3Py38_4.9.2\envs\QuantitativeTrading\python.exe` |
| 当前确认版本 | Python 3.10.14 |

## 依赖管理

项目依赖以仓库根目录的 `pyproject.toml` 为准。允许在 `QuantitativeTrading` 虚拟环境中安装项目运行、调试、测试所需的合理依赖。

建议优先使用该环境的Python解释器执行命令，例如：

```powershell
& 'D:\Coding\APPS\Miniconda3Py38_4.9.2\envs\QuantitativeTrading\python.exe' -m pip install -e .
```

## 注意事项

1. 不使用系统默认Python环境运行项目代码。
2. 不把Conda虚拟环境目录提交到项目仓库。
3. 数据样例位于 `data_example/`，运行生成的中间数据、缓存和输出结果应按 `.gitignore` 规则排除。
