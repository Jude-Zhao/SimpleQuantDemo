## 2. 详细设计

### 2.1 core/data/akshare_source.py

**(a) 2 年分段**（`_tencent_fetch_range`）：按年循环改为步长 2 的分段。模块常量 `_SEGMENT_YEARS = 2`（协议层参数，不进配置）。边界：`seg_end_year = min(year + 1, end_year)`，`seg_end = f"{seg_end_year}-12-31" if seg_end_year < end_year else end`。2021-01-04~2026-09-11 → 3 段：(2021-01-01, 2022-12-31)、(2023-01-01, 2024-12-31)、(2025-01-01, 2026-09-11)。

**(b) 删除 raw 拉取与 adj_factor**（`_fetch_hfq_price`）：删除 raw_rows 拉取、merge、`adj_factor = close/raw_close`、NaN 兜底分支；`_tencent_row_map` 不变；docstring 同步更新。

**(c) WAF 拦截不重试**（`_tencent_get`）：
- `status == 501` 或响应含 `waf.tencent.com` → **立即抛 `TencentSourceError`（携带 HTTP 状态），不进入重试循环**（不重试仅针对 WAF 拦截，与需求决策 5 口径一致）；
- 其他非 200（502/503/504 等瞬时服务端错误）、网络异常、坏 JSON → 保留 (1.0, 2.0, 4.0) 退避重试，耗尽抛 `TencentSourceError`；
- 正常应答（含空数据）不重试，现状保持。
