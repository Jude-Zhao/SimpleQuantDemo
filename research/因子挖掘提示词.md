## 3. 因子接口（必须严格遵守的骨架）

- 每个因子 = 工作子目录 `factors/` 下的**一个独立 `.py` 模块**，定义一个继承 `core.factors.base.FactorBuilder` 的类。
- 对评估流程来说，你只需要提供：一个 `build(...)` 方法 + `name` 属性 + 类级元数据。**模板如下，复制即用**：

```python
    registry_name = "momentum_your_idea"      # 唯一注册名（小写、下划线）

    category = "动量"                          # 四选一：动量/反转/波动/量能

```

- `pivot_price_field(price_data, field="close", universe=universe)` 把某一字段转成 **index=交易日、columns=universe** 的矩阵（列顺序与 `universe` 一致，已处理对齐）。`open/high/low/volume/amount` 均可这样取出。
- `build` 返回值的契约：**index 必须是 DatetimeIndex（交易日），columns 必须与 `universe` 顺序完全一致**；末尾调用 `validate_factor_matrix`（它会校验列序与必要属性）。
- 长窗口因子（如滚动 120 日）会导致早期若干交易日为 NaN，这是允许的——有效样本会自动排除，不影响判定。
- **禁止**：import/调用 `register_factor`、写 `if __name__ == "__main__"`、改动任何 registry / config / 项目文件。

### 3.1 构造思路参考（只作提示，非强制）

- 动量：`close/close.shift(n) - 1`、均线斜率、DIF 型。
- 反转：近期大涨后回落、（取负的）短期收益、对强势/弱势标的的反向打分。
- 波动：滚动收益标准差、最大回撤、下行半方差、波动率倒序（低波）。
- 量能：量价配合（价涨量放）、成交额趋势、OBV/MFI 类、（用 `amount` 而非裸 `volume` 更不易受基金份额变化干扰）。
- 个别标的存在缺价格日（如跨市场 ETF）：构造阶段只允许 `ffill()`（用**历史**信息补齐），**不得 bfill**（那会用未来价格污染当日信号，属于 lookahead）。

1. 首次运行前，在**工作子目录根**创建 `run_factor.py`，内容为下文【评估脚本模板】的**逐字副本，一字不改**。
2. 用法（可从任意目录执行，脚本会自动定位项目根与 DB）：
   ```

   ```
   示例（假设任务目录名为 `因子挖掘2026.08.23`）：
   ```

   ```
3. 脚本会：自动找到项目根与数据库 → `load_all("2021-01-04", 今日)` → 以**因子类默认参数**实例化 → 调用 `core.evaluate_factor(...)`（**固定评估口径**）→ 计算并打印「黄金护栏」判定与分年 RankIC → 把结果写入 `results/<因子模块名>.json`。
4. 你不必读懂脚本内部，只需看懂打印输出。**不要改动脚本中任何参数/口径。**

### 固定评估口径（由脚本强制，不可修改）

- 前向收益持有期 `horizon = 5`（交易日，T+1 执行）。
- `min_observations = 3`、`icir_window = 20`。
- 数据区间：`2021-01-04` 至当日的全样本。
- `backtest = False`（本任务只做 IC 数字评估，不跑组合回测）。
- 指标均基于 **RankIC（Spearman 截面秩相关）**；同时打印 Pearson IC 作参考。

### 评估脚本模板（复制为 `run_factor.py`）

```python
"""固定因子评估脚本（黄金护栏判定）。不可修改，勿改动固定口径。"""
from __future__ import annotations

import importlib.util
import json
import math
import sys
from pathlib import Path


def main(argv: list[str]) -> None:
    if len(argv) < 2:
        sys.exit("usage: python run_factor.py <factor_module.py>")
    factor_path = Path(argv[1]).resolve()
    if not factor_path.exists():
        sys.exit(f"factor module not found: {factor_path}")

    project_root = _find_project_root(factor_path)
    if project_root is None:
        sys.exit("cannot locate project root (data/simple_quant.db + pyproject.toml) upward from factor file")
    sys.path.insert(0, str(project_root))

    from core.data import SqliteDataSource
    from core.evaluate import evaluate_factor
    from core.factors.base import FactorBuilder

    module = _load_module(factor_path)
    builder_cls = _find_builder(module, FactorBuilder)
    if builder_cls is None:
        sys.exit("no FactorBuilder subclass found in the module")

    db = project_root / "data" / "simple_quant.db"
    res = evaluate_factor(
        builder_cls(),
        data_source=SqliteDataSource(db),
        start_date="2021-01-04",
        end_date=None,
        horizon=5,
        min_observations=3,
        icir_window=20,
        backtest=False,
    )

    rank_ic = res.rank_ic.astype(float).dropna()
    n_obs = int(len(rank_ic))
    if n_obs == 0:
        _finish(factor_path, res, {}, "NO_OBS",
                {"mean_rank_ic": None, "rank_icir": None}, "IC 无有效观测：因子全 NaN 或有效标的不足")
        return

    mean_ric = float(rank_ic.mean())
    std_ric = float(rank_ic.std())
    rank_icir = mean_ric / std_ric if std_ric > 1e-12 else float("nan")

    yearly = rank_ic.groupby(rank_ic.index.year).agg(["mean", "count"])
    valid_years = yearly[yearly["count"] >= 20]
    sign = 1.0 if mean_ric >= 0 else -1.0
    n_consistent = int((sign * valid_years["mean"] > 0).sum())
    n_years = int(len(valid_years))

    pass_main = abs(mean_ric) > 0.04 and abs(rank_icir) > 0.2
    pass_yearly = n_years >= 3 and n_consistent / n_years >= 0.6

    gate = {
        "name": res.name,
        "declared_direction": getattr(builder_cls, "direction", "?"),
        "n_observations": n_obs,
        "mean_rank_ic": round(mean_ric, 4),
        "rank_icir_mean_over_std": round(rank_icir, 4) if not math.isnan(rank_icir) else None,
        "ic_mean_pearson": round(res.ic_mean, 4),
        "yearly_mean_rank_ic": {int(y): round(float(r), 4) for y, r in valid_years["mean"].items()},
        "n_consistent_years": n_consistent,
        "n_valid_years": n_years,
        "pass_main": pass_main,
        "pass_yearly": pass_yearly,
    }
    verdict = "PASS" if (pass_main and pass_yearly) else "FAIL"
    _finish(factor_path, res, gate, verdict,
            {"mean_rank_ic": mean_ric, "rank_icir": rank_icir}, None)


def _find_project_root(start: Path) -> Path | None:
    cur = start.parent
    while True:
        if (cur / "data" / "simple_quant.db").exists() and (cur / "pyproject.toml").exists():
            return cur
        if cur == cur.parent:
            return None
        cur = cur.parent


def _load_module(path: Path):
    spec = importlib.util.spec_from_file_location("candidate_factor", path)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def _find_builder(module, base_cls):
    for _name, obj in vars(module).items():
        if isinstance(obj, type) and issubclass(obj, base_cls) and obj is not base_cls:
            return obj
    return None


def _finish(factor_path, res, gate, verdict, values, warning) -> None:
    results_dir = factor_path.parent.parent / "results"
    results_dir.mkdir(parents=True, exist_ok=True)
    out = results_dir / f"{factor_path.stem}.json"
    out.write_text(json.dumps({**gate, "verdict": verdict, "warning": warning},
                              ensure_ascii=False, indent=2), encoding="utf-8")

    print("\n================ 黄金护栏判定 ================")
    print(f"factor             : {gate.get('name')}")
    print(f"declared direction : {gate.get('declared_direction')}  (实测符号: {'positive' if values['mean_rank_ic'] is not None and values['mean_rank_ic'] >= 0 else 'negative'})")
    print(f"n_observations     : {gate.get('n_observations')}")
    print(f"mean_RankIC        : {gate.get('mean_rank_ic')}")
    print(f"RankICIR(mean/std) : {gate.get('rank_icir_mean_over_std')}")
    print(f"  |RankIC|   >0.04 ? : {abs(values['mean_rank_ic']) > 0.04 if values['mean_rank_ic'] is not None else False}")
    print(f"  |RankICIR| >0.2  ? : {abs(values['rank_icir']) > 0.2 if values['rank_icir'] else False}")
    print(f"分年 mean RankIC    : {gate.get('yearly_mean_rank_ic')}")
    print(f"  同向年份/有效年份 : {gate.get('n_consistent_years')} / {gate.get('n_valid_years')}")
    print(f"  pass_main         : {gate.get('pass_main')}")
    print(f"  pass_yearly       : {gate.get('pass_yearly')}")
    if warning:
        print(f"  warning           : {warning}")
    print(f"VERDICT            : {verdict}")
    print(f"结果已写入          : {out}")


if __name__ == "__main__":
    main(sys.argv)
```

## 5. 好坏判定 = 黄金护栏（唯一硬性标准）

一个因子**全部满足以下条件才判为「通过 / PASS」**：

1. **全期 |mean(RankIC)| > 0.04**（RankIC = Spearman 截面秩相关，样本为 2021-01-04 起所有有效交易日）。
2. **全期 |RankICIR| > 0.2**，其中 `RankICIR := mean(rank_ic) / std(rank_ic)`（标准全期定义，非滚动窗口均值）。
3. **方向一致**：因子 `direction` 元数据与实测 `mean(RankIC)` 的符号一致（脚本会打印实测符号供你核对）。
4. **分年稳健**：对每年 RankIC 观测数 ≥ 20 的有效年份：若有效年份 ≥ 3，则其中 **≥ 60%** 年份的单年均值与全期符号相同。

若不满足，记为「未通过 / FAIL」，如实记录数值到报告，不进最终推荐。

### 5.1 微调守则（防过拟合）

- 未通过但接近（例如 |mean(RankIC)| > 0.03 或 |RankICIR| > 0.15）时，允许**调整参数窗口**（仅改 `__init__` 默认参数的数值）重试。
- 每个因子参数微调**至多 2 次**；每次只改参数数值范围，不改变因子逻辑。
- **禁止**：(a) 事后挑选特殊窗口/子区间来强行达标；(b) 对窗口做数以千计的网格搜索博弈到达标；(c) 修改评估脚本或口径来让结果好看。
- 若 2 次微调后仍未达标，就如实判定 FAIL 并记录，转向下一个假设。

### 5.2 差异化约束

避免与既有生产因子功能重复。已知既有因子：
- 动量 `macd_hist`；反转 `skewness_60_reversal`；波动 `drawdown_120`；量能 `mfi`、`psy20`。

你的新因子应有**不同的信号来源/逻辑**（只是窗口不同不算增量）。在假设卡片中写明「与既有因子的差异点」。

## 7. 迭代流程与红线

### 建议的执行顺序

1. **分配**：在 4 个方向间分配注意力，每方向给 1–3 个**可解释**假设（先写假设再写码）。
2. **实现**：按 §3 模板写因子模块到 `factors/`。
3. **评估**：按 §4 建好 `run_factor.py` 后逐个 `python run_factor.py <因子模块>`。
4. **判定**：PASS → 保留并写 `_report.md`；接近 → 微调（≤2 次）；否则 FAIL 记录。
5. **收尾**：写 `因子挖掘报告.md` 汇总。

### 红线（违反即判整轮失败）

- **任何未来函数 / lookahead**：t 日因子只能用截止 t 日收盘及更早的信息；不得使用 t、t+1 及以后的任何数据。（前向收益由脚本 T+1 口径保证，你只需保证因子矩阵本身不用未来。）
- **不按交易日对齐**的收益/调仓/窗口位移。
- 使用非指定字段、外源行情或宏观数据。
- 改动项目其它目录的文件（§0 写文件边界）。
- 修改评估脚本或其固定参数/口径。
